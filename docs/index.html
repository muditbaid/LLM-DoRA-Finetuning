Introduction

The Core Problem: Fragmented Supervision

Real-world posts overlap categories

A single post can contain hate speech + profanity + threatening language simultaneously , yet most benchmarks treat these as separate binary tasks.

No unified multilabel benchmark exists

Bumler et al. (2025) reviewed 46 studies, found 28 datasets : zero covering hate, offense, bully & threat under one consistent schema.

Cross-dataset generalization fails

Antypas & Camacho-Collados (2023) showed models trained on one dataset exhibit persistent bias on others due to annotation drift.

Literature Review

Prior Work: What Exists & What Doesn't

Binary Datasets

  • • Davidson et al. (2017) - 25K tweets, 3-class
  • • OLID/OffensEval (2019) - hierarchical offensive labels
  • • DynaHate (2021) - adversarial, 4-round dynamic collection
  • • Table 2.1 summarizes 9 key studies

Multilabel Resources

  • • Jigsaw Toxic (2018) - 160K, 6 labels, Wikipedia only
  • • ETHOS (2022) - 998 posts, attribute-focused
  • • HateXplain (2021) - rationale annotations, not flat multilabel
  • • None cover hate+offense+bully+threat together

Detection Models

  • • Pre-DL: LR + TF-IDF, SVM, Naive Bayes
  • • Deep: CNN/BiLSTM + Word2Vec/GloVe
  • • Transformers: BERT, HateBERT, RoBERTa → SOTA
  • • LLMs: GPT-4, LLaMA - prompt-sensitive, costly

Ensembles & MoE

Shazeer et al. (2017) sparse gating; Mixtral (2024) sparse MoE : both use latent neural gates. Symbolic-MoE (Chen et al., 2025) introduces human-readable skill routing, which this thesis adapts to harmful-language detection.

Research Gap → This Thesis

No prior work combined: (1) heterogeneous binary experts + (2) dynamic per-instance routing + (3) interpretable symbolic skills + (4) multilabel output. See Table 2.1.

Methodology - Routing

Two Routing Strategies (Table 4.4)

Baseline: Log-Odds Router

Follows Symbolic-MoE (Chen et al., 2025). Expert score = global prior log-odds + sum of per-skill log-odds from inferred skills only. Absent skills ignored.

score(e) = prior(e) + Σ logodds(s,e) for s ∈ S_present

Proposed: Bernoulli Router ✨

Models each skill as a Bernoulli variable per expert. Uses both presence and absence of skills as informative signal. Even empty-skill posts get a meaningful ranking.

score(e) = log P(e) + Σ log P(s|e) + Σ log(1-P(s|e))

s_present / s_absent over full 11-skill vocabulary

Evaluation Protocol

Multi-expert evaluation under fragmented supervision: a prediction is correct if the gold label is produced by any activated expert.

Evaluation Protocol

How We Measure Multi-Expert Performance

Multi-Expert Correctness

A prediction is correct if the gold normalized label is produced by any of the top-k routed experts. Mirrors the system's multi-alert design intent.

Routing Metrics

Top-1 Accuracy: highest-ranked expert matches gold expert. Gold-Expert Recall @top-k: correct expert appears in top-k ranked list.

Task Performance Metrics

Per-expert Accuracy and Macro F1 on both validation and test splits. Reported across four benchmarks independently.

Not a Standard Multilabel Eval

Since no single shared gold multilabel annotation exists, evaluation occurs within each benchmark's label space. The test assesses whether correct task experts are activated, not joint prediction of all four categories on one post.

Key Design Principle

Pool separation is enforced: expert profiles built from profile pool only → routing calibrated on validation pool → final metrics on held-out test pool (1,920 posts). No data leakage.

Chapter 6

Conclusion

RQ1 Answered ✓

Binary specialists coordinated via symbolic routing do recover meaningful multilabel behavior - overall macro F1 ≈ 0.93 across four heterogeneous benchmarks.

RQ2 Answered ✓

Bernoulli router improves top-1 routing accuracy (+4.7 pp) and gold-expert recall @top-2 (+20.5 pp) over log-odds baseline on validation pool.

RQ3 Answered ✓

Symbolic skills + expert profiles create fully auditable chains: post → skills → expert ranking → predictions. Misrouting diagnostically traceable.

Key Takeaway

A modular, interpretable MoE approach to harmful-language detection is viable and practical under realistic academic compute. No unified multilabel dataset required - fragmented supervision can be coordinated.

Broader Impact

Framework enables transparent moderation auditing - each routing decision is traceable to human-readable skills, addressing accountability requirements in real-world content moderation policy.

Chapter 6.2

Limitations & Future Work

Current Limitations (RQ4)

⚠

No shared gold multilabel annotation - evaluation is per-benchmark, not truly joint multilabel. Cannot measure all four categories on the same post.

⚠

Routing partial selectivity - high-frequency overlapping skills (coded hostility, general insult) dilute routing precision due to inherent conceptual overlap across harmful categories.

⚠

Annotation biases inherited - all four benchmarks reflect known dataset biases (platform-specific, demographic over-flagging). Routing cannot correct upstream annotation noise.

⚠

Inference cost - 5-run stochastic skill inference × 4 experts adds latency unsuitable for real-time moderation at scale.

Future Directions

Build a true multilabel benchmark

Annotate a shared corpus with hate + offense + bully + threat simultaneously for rigorous joint evaluation.

Expand skill vocabulary

Richer skill ontology could improve routing discrimination in the symbolic overlap zone.

Efficient single-pass skill inference

Distill stochastic 5-run inference into a single efficient skill classifier for production-scale use.

Extend to multilingual & multimodal

Apply routing framework to non-English content and image+text posts prevalent in social media.
